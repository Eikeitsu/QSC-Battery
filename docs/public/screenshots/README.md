# WebUI 截图维护

文档与 README 引用本目录下的界面示意图：

| 文件 | 对应页面 |
| --- | --- |
| `webui-overview.svg` | 概览 |
| `webui-config.svg` | 策略 |
| `webui-log.svg` | 日志 |
| `webui-more.svg` | 我的 |

当前为 **结构示意 SVG**（英文标注、纯 ASCII），便于文档站离线展示且避免编码问题。发版前可用真机 WebUI 截图替换（保持同名 `.png` 或 `.svg`，并同步更新 `docs/guide/*.md` 中的扩展名）。

建议截图环境：

- KernelSU 管理器或 MMRL 打开模块 WebUI
- 状态为「充电中」或「已停充」且策略已配置
- 策略页展示电量 / 温控与电流控制区块（若已安装）
- 我的页展示主题包与显示选项

分辨率建议宽度 360–390px，PNG 即可。
