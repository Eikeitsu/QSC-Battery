# WebUI 使用说明

WebUI 在模块管理器中打开（KernelSU、SukiSU、APatch 系、MMRL、WebUI-X 等）。底部四页：**概览 · 策略 · 日志 · 我的**。三套主题包：默认 / MD3 / MIUIX；深浅色可跟随系统。

## 打开方式

1. 安装时选择安装 WebUI
2. 重启后进入 **充电控制 → WebUI**
3. 需要管理器提供 shell 桥接（普通浏览器不行）

若提示未检测到桥接，请换支持模块 WebUI 的客户端。

## 概览

- 实时电量、温度、充电/停充状态、软开关
- 当前策略摘要
- 充放电曲线（受 `chart_show` / `history_enable` 控制）：范围切换、降采样与平滑、增量刷新、健康趋势
- 下拉刷新

## 策略

| 区域                  | 内容                                                                  |
| --------------------- | --------------------------------------------------------------------- |
| 电量停充              | 停止/恢复、延时、时段、充满再停                                       |
| 停充行为              | 持锁、拔插、兼容模式、通知种类、勿扰、常显功耗                        |
| 温度停充              | 开关与阈值                                                            |
| 电流控制              | 旁路/慢充/温控限流/游戏限流（仅已装组件时显示）                       |
| **省电策略**          | 档位（均衡/强力/自定义）、息屏加强、夜间时段、深睡；读写 `power.conf` |
| 首选开关 / 自定义开关 | 档案与 `power_switch`                                                 |
| 测开关与缓存          | 快速/完整测开关、清缓存                                               |
| 进阶                  | 无线、App 停充、历史/曲线、动态简介等                                 |
| 事件守护              | qscd 开关、rust/c、下载/检查/卸载；**只读快照与诊断**；切换实现时 **升级继承** 已下载守护 |

保存后一般立即生效；部分项依赖下一轮服务循环。

守护说明：Rust / C 职责不同——Rust 可做阈值事件过滤与进程检测；C 更轻量。二者都是只读监听，**不写任何充电节点**（停充仍由 Shell 执行）。

## 日志

两个 Tab：

1. **运行日志**：级别过滤、会话视图、清空。可见「进入/退出息屏·夜间·深睡」、驻停总结；开启诊断后还有周期性「省电统计」
2. **充电事件**：插拔、停充、温控等结构化事件

自查命令见 [CLI](/guide/cli)（`qsc stats` / `qsc diagnostic on`）与 [FAQ 待机](/guide/faq#standby)。

## 我的

- 外观：主题包、深浅、莫奈/色值、底栏与紧凑选项（多存本机）
- 配置档：导出/应用多套 `config`
- 设备档案库：压缩/还原 `device.profile`
- 社区机型预设与节点分享
- 关于、致谢、捐赠入口

## 热更新与诊断路径

跨安装器热更新资料可能在：

```text
/data/adb/qsc/hot_update/
/data/adb/qsc/runtime/diagnostics/hot_update.log
```

平时可忽略；更新完成后会清理。运行期停充标记仍在模块 `data/`。

## 与 APP 的关系

WebUI 与伴侣 APP 读写同一套模块配置。可只装其一，或两者同用。APP 另有主题图标、磁贴、LSPosed 状态等，见 [伴侣 APP](/guide/app)。
