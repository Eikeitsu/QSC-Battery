# 功能介绍

**充电控制**（仓库名 QSC-Battery，模块 id `QSC_Battery`）是运行在 Magisk / KernelSU 上的充电管理模块，基于 top大佬原作 QSC 定量停充，由许小墨维护 WebUI 与扩展能力。

## 它能做什么

- **按电量停充**：电量达到设定上限后停止充电，降到恢复值后再继续充
- **按温度停充**：电池温度过高时停充，温度回落后恢复
- **充满再停**：到达 100% 后等待涓流结束再停充，更贴近「真正充满」
- **自动拔插**：插入充电器时模拟一次拔插，有助于激活快充
- **兼容模式**：与其它快充/限流模块同装时可开启，跳过本模块电流控制，只保留电量/温度停充
- **停充开关实测**：插电后在 Action 诊断菜单测试可逆有效节点，写入 `preferred_switch`，停充更稳
- **电流控制（安装时可选）**：通过通用 sysfs 调节充电电流——模拟旁路、慢充、默认限流、温度一限/二限、游戏限流；总开关默认关闭。旁路有独立开关，开启后可按**电量 / 温度 / 时段**（支持跨天）任一条件自动触发；默认模拟写电流，可选「自动」仅在本机已有旁路节点时尝试；过热会改用小电流。不改温控文件、不做内核补丁。未配置节点时只写单一安全 `*_max`，避免错误节点导致重启。
- **动态简介**：模块管理器列表中的简介会随运行状态变化（启动、充电、停充原因、电流控制模式、异常等）
- **WebUI**：图形界面改配置，实时状态与日志一目了然；游戏列表可搜索勾选已安装应用

## 适用场景

| 场景         | 建议                                                   |
| ------------ | ------------------------------------------------------ |
| 过夜充电     | 停止 80–90%，保护电池                                  |
| 游戏 / 导航  | 开启温控，高温自动停充；可选游戏限流                   |
| 需要满电出门 | 临时把停止电量设为 100，或关闭电量停充（停止值填 110） |
| 边玩边充降温 | 安装电流控制后开启模拟旁路 / 慢充（效果因机而异）      |

## 运行方式

开机后 `service.sh` 循环执行核心脚本，约每 3 秒检查一次电量与温度，满足条件时写入充电控制节点（有 `preferred_switch` 时优先；MCA 仍优先于通用节点）；若已安装电流控制且总开关开启且未开兼容模式，则在未停充时按策略写电流节点。

停充配置：

```text
/data/adb/modules/QSC_Battery/config/config.conf
```

电流控制配置（仅安装该组件时存在）：

```text
/data/adb/modules/QSC_Battery/config/current.json
```

运行日志：

```text
/data/adb/modules/QSC_Battery/data/log.log
```
